# Gestión Puerto Ayacucho

Sistema de gestión para Puerto Ayacucho.

## Cómo usar

Este repositorio contiene el proyecto.

Para ver la página principal, abre el archivo `Gestion-Puerto-Ayacucho.html` o `sistema.html` en el navegador.

## Despliegue

Puedes usar GitHub Pages o Vercel (ya tiene `vercel.json`).

## Archivos principales

- `Gestion-Puerto-Ayacucho.html` / `sistema.html` — Página principal del sistema
- `package.json` — Dependencias del proyecto (Vite + React + TanStack)
- `src/` — Código fuente de la aplicación

**Nota:** El proyecto completo (zip) se puede subir fácilmente arrastrando y soltando los archivos desde la interfaz web de GitHub (botón "Add file" → "Upload files").
